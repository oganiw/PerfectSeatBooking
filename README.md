# 法會－公關輔助劃位器

法會當天的功德主「供燈波次」與「座位」輔助排位工具。只有一個網頁檔（`index.html`），用瀏覽器開啟即可，**不需要安裝、不需要登入、不需要伺服器**。

> 所有名單都只在你自己的瀏覽器裡處理，**不會上傳到任何地方**。關掉或重新整理頁面，資料就會清掉，所以請先下載結果再離開。

## 能做什麼

依你提供的名單與佈場圖，自動排出：

- **供燈順序（波次）**：依功德項目次第，預設每波 4 人，可手動調整，調整後後面的波次會自動重排。
- **座位**：東單男眾、西單女眾；男眾超出時排到西單整排，同一排不混排男女（夫妻除外）；區分椅子與拜墊。
- **匯出 Excel**：直接填進你自己的樣板，產生
  - 供燈排序表（含「發心項目的人數及備燈」統計）
  - 總座位圖、公告座位圖
  - 給心燈照客版、給師父版
  - 座位對照表

## 使用步驟

1. **上傳資料**：功德主名單（全）、已報名名單、佈場圖／樣板 Excel。
2. **確認出席**：依報名狀況判定誰有來，可手動勾選。
3. **供燈順序**：檢視自動排好的波次；可用 ↑↓、波次數字或勾選後移動來調整。
   - 身分／座位可選：一般功德主、義工（有座位／無座位）、不進波次（有座位／無座位）。
   - 親眷可選：上台供燈、自行供燈（有座位、不唱名、不胸花、需備燈）、不供燈。
4. **排座位**：點選兩個座位互換，或直接拖曳座位框；可標記「男眾座位區」「保留」。
5. **下載 Excel**。
6. **座位對照表**：姓名與座位的對照。

## 名單格式重點

- 已報名名單欄位：登入名稱／姓名、義工執事、功德主、是否報名、關聯親眷。
- 功德主可能不是學員本人，而是已報名學員的「關聯親眷」，程式會一併判斷是否有來，並讓該學員跟同一波供燈。
- 義工執事預設上台供燈、不排座位；醫護若不是功德主，會排在最後靠邊。

## 放到 GitHub Pages（免安裝、免指令）

1. 在 GitHub 建立新的 repository（例如 `seat-planner`）。
2. 網頁上點 **Add file → Upload files**，把 `index.html` 和 `README.md` 拖進去，按 **Commit changes**。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/seat-planner/`。

### 之後要更新

在 repository 點 `index.html` → 右上角鉛筆（Edit）或 **Add file → Upload files** 重新上傳同名檔案即可，網址不變。

## 注意事項

- 免費帳號的 GitHub Pages 需要**公開（public）repository**，知道網址的人都能開啟這個工具。工具本身只有排位規則，沒有任何名單資料。
- **請勿把名單、報名表或匯出的 Excel 放進 repository**，裡面有個人資料。
- 公司電腦使用外部平台前，請先確認公司規定。
- 建議使用 Chrome、Edge 或 Safari 的最新版本。
- 座位上的椅子男女眾判斷，仍請人工確認後再手動調整。
